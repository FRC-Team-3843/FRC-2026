## Build & run

- Build requires the WPILib JDK17; system `java` is 8. From `2026Robot\`: `JAVA_HOME="C:/Users/Public/wpilib/2026/jdk" ./gradlew build` (also `deploy` / `test` / `simulateJava`). (from: frc-2026-build-env-java17)
- Build/deploy/test commands are project-dir-scoped — `cd 2026Robot` first, not repo root. (source: STANDARDS.md)

## Coding standards

- STANDARDS.md is the team's "read first" file and single source of truth; strict command-based + dependency injection, `RobotContainer` is the only instantiation/binding site, no global static subsystem access. (from: frc-2026-api-standards)
- 2026 motor APIs only: `SparkMax`/`SparkMaxConfig` (not `CANSparkMax`); Phoenix6 control-request objects; Phoenix Pro features forbidden; NO warning suppression; don't copy FRC-2024/2025 patterns un-refactored. (from: frc-2026-api-standards)

## Hardware / architecture

- Mirrored double-turret shooter: NEO 550 turrets (52.987:1, ±110°), Kraken X44 preshooters (0.625), Kraken X60 main shooters (0.917); intake chain X44 roller → NEO 550 conveyor → Bag-motor hopper → NEO 550 feeder. (from: frc-2026-shooter-swerve-hardware)
- Swerve = YAGSL on MK4 **L1**, drive **8.14:1**, angle **12.8:1**, ~3.71 m/s per repo docs. NOTE: external memory carried different ratios (5.8267:1 / 12:1 / "inversion plate") — repo docs win; the divergence is unresolved (see note Open Questions). (from: frc-2026-shooter-swerve-hardware)
- CAN map: swerve 11-22, mechanisms 30-39, hood servos PWM 0/1, NavX on SPI. Full CAN tables + controller bindings in `2026Robot\TODO-COMPETITION.md` and `NOTES.md` §0B. (source: NOTES.md, TODO-COMPETITION.md)

## Vision

- PhotonVision runs headless on a Beelink coprocessor (heavy AprilTag work off the RIO; RIO fuses poses + aims turrets). Reachable on the robot network at `http://10.38.43.11:5800`, team 3843, NT client mode. (from: frc-2026-shooter-swerve-hardware)
- `ENABLE_VISION` stays false until the right camera is mounted + calibrated; coded camera transforms are estimates. (source: README.md, NOTES.md §3.2)
